# .kilo/commands/

Команда — это промпт, который вы сохранили, чтобы не писать его заново. Один файл
`<имя>.md` = одна команда агента, вызывается в сессии как `/<имя>`.

Шаблон:

```markdown
---
description: Одна строка о том, что делает команда
---

Ты — <роль>. Вход: <файлы>.
Сделай: <что именно>.
Ограничения: <чего нельзя>.
Выход: <какой файл и с какой структурой>.
```

Что здесь появится по ходу практикума:

- `selfreview.md` — саморевью PR против плана и спеки;
- `judge-intent-spec.md` — судья по паре intent/spec (ДЗ.1 ★);
- `spec-review.md` — разбор спеки на неоднозначности.

Хорошая команда отличается от хорошего промпта одним: её можно запустить через
месяц на другой задаче, и она всё ещё осмысленна.
