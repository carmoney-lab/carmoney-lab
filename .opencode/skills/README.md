# .opencode/skills/

Скилл — это папка с файлом `SKILL.md`, который агент подхватывает, когда задача
подходит под его описание. Формат:

```
.opencode/skills/<имя-скилла>/
├── SKILL.md          # что за навык, когда применять, пошаговая инструкция
└── references/       # необязательно: примеры, шаблоны, таблицы
```

Минимальный `SKILL.md`:

```markdown
---
name: carmoney-domain
description: Словарь предметной области и правила расчёта LTV. Применять, когда
  задача касается заявки, оценки авто или решения approve/review/reject.
---

# Когда применять
...

# Как делать
1. ...
```

Во фронтматтере OpenCode читает только `name`, `description`, `license`,
`compatibility` и `metadata`; остальные поля игнорируются молча. `name` — строчные
латинские буквы и дефисы, совпадает с именем папки.

Кроме `.opencode/skills/` OpenCode сканирует `.claude/skills/` и `.agents/skills/`
(и их глобальные двойники в `~/.config/opencode/`, `~/.claude/`, `~/.agents/`).
Поэтому чужую библиотеку под Claude Code можно положить как есть. Скиллы кладём
**в проект и в git**, а не глобально: в 2.1 сравниваются прогоны с разными
библиотеками, и глобальная установка их перемешает.

Первые скиллы вы пишете в ДЗ 1 → 2 и в 2.3. Пока каталог пустой — это нормально.
