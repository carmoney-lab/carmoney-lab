# docs/

Каждый шаг практикума оставляет после себя файл, который читает следующий шаг.
Цепочка артефактов задачи LOAN-12 выглядит так:

```
sources/LOAN-12.md          материалы кейса — выданы (вход)
      ↓
sources/LOAN-12_raw.md      выжимка из материалов со ссылками (1.5)
      ↓
intent/intent_LOAN-12.md    замысел: что и зачем (1.6)
      ↓
spec/spec_LOAN-12.md        требования REQ и критерии приёмки AC (1.7)
      ↓
plan/plan_LOAN-12.md        файлы, шаги, риски (1.10)
      ↓
код + tests/                реализация по плану (1.11, 1.13)
      ↓
review/selfreview_LOAN-12.md  сверка diff с планом и спекой (1.12)
      ↓
qa/acceptance_LOAN-12.md    чек-лист приёмки (1.14)
      ↓
deploy/deploy_d1.md         локальный запуск и стенд (1.18)
```

| Каталог | Что кладут | Когда |
|---|---|---|
| [`sources/`](sources/) | материалы кейсов и выжимки из них | 1.5 |
| [`intent/`](intent/) | замысел изменения | 1.6 |
| [`spec/`](spec/) | требования и AC | 1.7 |
| [`plan/`](plan/) | план реализации | 1.10 |
| [`review/`](review/) | отчёты ревью и вердикты | 1.12 |
| [`qa/`](qa/) | чек-листы приёмки | 1.14 |
| [`deploy/`](deploy/) | запуск локально и на стенде | 1.18 |
| [`security/`](security/) | red team и prompt injection | 2.20, 3.26 |
| [`metrics/`](metrics/) | токены, деньги, FinOps | 1.4, 3.33 |
| [`setup/`](setup/) | установка инструментов и подключение MCP | до 1.5 |
| [`agent-rules.md`](agent-rules.md) | права и правила агента | ДЗ.6, 2.16, 2.20, 3.7, 3.26 |

Имя файла — `<тип>_<ID задачи>.md`. ID задачи: `LOAN-12` в дне 1, `CASE-NN` вашей команды в днях 2–3.
В каждой папке лежит свой README с форматом — прочитайте его перед первым файлом.
