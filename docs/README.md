# docs/

Каждый шаг практикума оставляет после себя файл, который читает следующий шаг.
Цепочка артефактов дня 1 — учебная фича «пробег авто не больше 400 000 км, иначе решение
`review`» (ID `MILEAGE`):

```
setup/kilo_hello.md         первый ответ агента (1.4)
      ↓
setup/code_map.md           карта кода и точка вставки правила (1.6)
      ↓
AGENTS.md + kilo.jsonc      правила и права агента (1.8–1.9)
      ↓
setup/permissions_check.md  проверка инъекцией и ловушкой порога (1.10–1.11)
      ↓
plan/plan_MILEAGE.md        план до кода, агентом planner (1.14)
      ↓
intent/intent_MILEAGE.md    замысел через интервью Grill Me (1.16)
      ↓
metrics/tokens_d1.md        замер токенов с ast-index и Caveman (1.17–1.18)
      ↓
setup/e2e_check.md          проверка сервиса агентом через Playwright (1.19)
      ↓
spec/spec_MILEAGE.md + код  домашнее задание ДЗ.1
```

| Каталог | Что кладут | Когда |
|---|---|---|
| [`setup/`](setup/) | установка инструментов, карта кода, проверки агента | 1.4–1.19 |
| [`plan/`](plan/) | план реализации | 1.14 |
| [`intent/`](intent/) | замысел изменения | 1.16 |
| [`metrics/`](metrics/) | токены, деньги, FinOps | 1.17–1.18, 3.33 |
| [`spec/`](spec/) | требования и AC | ДЗ.1 |
| [`sources/`](sources/) | материалы кейсов и выжимки из них | дни 2–3 |
| [`review/`](review/) | отчёты ревью и вердикты | дни 2–3 |
| [`qa/`](qa/) | чек-листы приёмки | дни 2–3 |
| [`deploy/`](deploy/) | запуск локально и на стенде | дни 2–3 |
| [`security/`](security/) | red team и prompt injection | 2.20, 3.26 |
| [`agent-rules.md`](agent-rules.md) | права и правила агента | 1.9, 2.16, 2.20, 3.7, 3.26 |

Имя файла — `<тип>_<ID задачи>.md`. ID задачи: `MILEAGE` в дне 1, `CASE-NN` вашей команды в днях 2–3.
В каждой папке лежит свой README с форматом — прочитайте его перед первым файлом.
