# docs/metrics/

Расход токенов и деньги. Экономия, которую не измерили, ничего не стоит.

| Файл | Что внутри | Когда |
|---|---|---|
| `tokens_d1.md` | личный замер «до / после» Caveman и RTK | 1.4 |
| `tokens_t<NN>.md` | командный замер | 2.12, ДЗ 2 → 3 |
| `budget_<EPIC-X>.md` | бюджет эпика | 3.4 |
| `metrics_<EPIC-X>.md`, `raw/` | итоговые метрики и сырьё | 3.33 |

Минимальная таблица замера:

| Замер | input | output | $ | время | ответ остался верным? |
|---|---|---|---|---|---|
| до |  |  |  |  |  |
| после |  |  |  |  |  |

Колонка качества обязательна: сжатый ответ, который стал неверным, — не экономия.
Ключей и токенов в этих файлах нет. Цифры берутся из OpenRouter → Activity.
