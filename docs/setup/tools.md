# Инструменты: что поставить на ноутбук

Всё ставится локально, к себе. Ссылки и точные команды установки в таблицах ниже
**уточнит ведущий** перед тренингом — до этого момента в ячейках стоит прочерк.

## 1. База

| Что | Зачем | Проверка |
|---|---|---|
| Git | без него ничего | `git --version` |
| GitHub CLI (`gh`) | PR из терминала | `gh auth status` |
| Docker + Docker Compose | поднять сервис локально | `docker compose version` |
| PHP 8.3 + Composer | тесты и линтер без Docker | `php -v`, `composer -V` |
| IDE | VS Code / Cursor / JetBrains | — |

Docker'а нет и поставить нельзя? Это рабочий вариант: локально останутся `make test`
и `make lint`, а сервис вы поднимете на стенде (упражнение 1.18).

## 2. Агент

| Что | Ссылка на репозиторий | Команда установки | Проверка |
|---|---|---|---|
| OpenCode | _уточнит ведущий_ | _уточнит ведущий_ | `opencode --version` |

**Запуск:** терминал внутри IDE (VS Code / Cursor — встроенный терминал,
JetBrains — вкладка Terminal). Отдельного интерфейса осваивать не нужно.

**Ключ модели.** `OPENROUTER_API_KEY` живёт в окружении вашего ноутбука — не в
репозитории, не в `.env`, не в промпте:

```bash
echo 'export OPENROUTER_API_KEY="<ваш ключ>"' >> ~/.zshrc && source ~/.zshrc
```

Модели по умолчанию: **MiniMax M3** — генерация и частые прогоны, **GLM 5.3** —
план, ревью, судья. Ревьюер и судья работают на модели, отличной от модели автора.

Замер расхода — вкладка **OpenRouter → Activity**: input, output и $ по каждому запросу.

```bash
git --version && gh auth status && docker compose version
php -v && composer -V
opencode --version
echo "${OPENROUTER_API_KEY:0:7}…"   # должно быть непусто, ключ целиком не печатаем
```
