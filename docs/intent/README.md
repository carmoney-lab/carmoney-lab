# docs/intent/

Замысел одного изменения: **что и зачем**, без решений о реализации.

Имя файла: `intent_<ID задачи>.md` — например, `intent_LOAN-12.md`.

Разделы строго в этом порядке:

1. **Problem** — какая проблема решается.
2. **Proposed outcome** — как выглядит результат.
3. **Affected users and systems** — кого и что задевает.
4. **Constraints** — ограничения, со ссылкой на id фрагмента в `sources/`.
5. **Open questions** — у каждого вопроса роль-владелец: риск-менеджер, продакт, юрист, ИТ.

Не больше одной страницы. Классов, таблиц БД и эндпоинтов здесь нет — это `plan/`.
Не путайте с `AGENTS.md`: intent про одно изменение, AGENTS.md — про весь проект.

Появляется в упражнении 1.6.
