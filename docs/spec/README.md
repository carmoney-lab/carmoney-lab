# docs/spec/

Требования и критерии приёмки: **что именно считается сделанным**.

Имя файла: `spec_<ID задачи>.md` — например, `spec_LOAN-12.md`.

- Требования — `REQ-<задача>-NN`, одно проверяемое утверждение со ссылкой на источник.
- Критерии приёмки — `AC-<задача>-NN`, формат Given / When / Then, у каждого ссылка на REQ.
- На каждое числовое правило — минимум один AC **на границе**: ровно на пороге и сразу за ним.
- Бизнес-таблицы (пороги LTV, возраст авто) — только из источников, с id.
- Open questions из intent — у каждого статус «закрыт (чем)» или «перенесён (куда)».

Слов «быстро», «удобно», «корректно» без числа или условия в спеке нет.
Как реализовывать — не здесь, это `plan/`.

Начиная с дня 3 спека эпика замораживается (`v1`, тег, `SPEC_SHA256`), и правка идёт
через PR с меткой `spec-change` и одобрением Хранителя спеки по CODEOWNERS.

Появляется в упражнении 1.7.
