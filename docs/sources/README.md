# docs/sources/

Сырьё из источников — **дословно, без интерпретаций**. Сюда агент складывает то,
что выгрузил через MCP `lab-sources`: тикеты, страницы регламентов, выгрузки данных.

Имя файла: `<ID задачи>_raw.md` — например, `LOAN-12_raw.md`.

Что должно быть у каждого фрагмента:

- источник: инструмент MCP + id фрагмента;
- дата;
- дословная выдержка или таблица.

В конце файла — список расхождений между источниками. Разрешать их здесь не нужно:
противоречие фиксируется, а решение принимается в `intent` и `spec`.

Правило: в этом файле нет выводов, оценок и решений. Как только появилось «значит,
нужно сделать…» — это уже `intent/`.

Появляется в упражнении 1.5.
