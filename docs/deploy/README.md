# docs/deploy/

Как сервис поднимается локально и выкатывается на стенд.

Имя файла: `deploy_d<день>.md` — например, `deploy_d1.md`.

Что должно быть внутри:

- локальный URL и URL стенда (порт — из вашего диапазона);
- команды запуска, выката и остановки;
- вывод `curl` по двум проверкам из чек-листа приёмки;
- команда отката на стенде.

Границы на стенде: только ваш пользователь, каталог `/srv/<login>/`, проект
`docker compose -p <login>` и порты из вашего диапазона. Чужие контейнеры, сети и тома
не трогаем, `docker system prune` и `docker volume rm` — только с явного «да» человека.

Появляется в упражнении 1.18.
