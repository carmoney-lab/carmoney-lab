# .agent/ — обвязка агента

Здесь живёт всё, что делает агента управляемым. Это такой же код проекта, как
`backend/`: он ревьюится, коммитится и переживает смену модели.

| Каталог / файл | Что внутри | Когда заполняется |
|---|---|---|
| `skills/` | переиспользуемые навыки: `<имя>/SKILL.md` (+ `references/`) | ДЗ 1 → 2, 2.2 |
| `commands/` | готовые промпты как команды агента: `<имя>.md` | 1.12 ★★, ДЗ 1 → 2 |
| `hooks/` | детерминированные проверки git: `pre-commit` и то, что он вызывает | 1.17, 2.16, 3.7, 3.26 |
| `permissions.md` | человекочитаемая копия прав агента | ДЗ.6, дополняется в 2.16, 2.20, 3.7, 3.26 |

Источник истины по правам — конфиг агента в репозитории (блок `permission` в
`opencode.json`). `permissions.md` — его читаемая копия для людей и ревью.

Хуки подключаются один раз на репозиторий:

```bash
git config core.hooksPath .agent/hooks
```

Каталоги специально пустые: обвязку под себя вы собираете сами на занятии.
