# Права агента

Человекочитаемая копия прав. **Источник истины — конфиг агента в репозитории**
(блок `permission` в `opencode.json`): именно он реально что-то запрещает.
Этот файл нужен, чтобы права можно было прочитать и обсудить на ревью.

Принцип: сначала запрещено всё, потом разрешается только нужное.

## Стартовый набор

| Действие | Решение | Почему |
|---|---|---|
| Чтение и правка `backend/`, `frontend/`, `tests/`, `docs/` | allow | основная работа |
| Чтение `.env*` | **deny** | секреты не должны попадать в контекст модели |
| Правка `.env*` | **deny** | то же |
| `scripts/reset_db.sh` | **deny** | удаляет все данные учебной базы |
| `docker compose` в пределах своего проекта | allow | своё окружение |
| `docker system prune`, `docker volume rm` | **ask** | задевает чужие контейнеры и тома |
| `git commit`, `git push` в свою ветку | allow | сдача идёт через PR |
| `git commit --no-verify`, правка `core.hooksPath` | **deny** | обход хуков |
| `git push --force` в `main` | **deny** | необратимо |
| Сетевые запросы наружу (`curl`, `wget`) | **ask** | канал утечки данных |
| Правка `.github/`, `AGENTS.md`, `.agent/` | **ask** | это сама обвязка |

## Проверка

Права проверяются атакой, а не чтением. Сформулируйте 3 атаки (2.20), запустите
их на своём агенте и впишите сюда то, что реально не сработало.
